# Lilopia

A small, mobile-friendly pretend-play prototype for the Lilopia game. Open `index.html` directly in a browser, or run a local static server from this folder (for example, `python -m http.server 8000`).

## In this prototype

- Three starter play spaces: Sunny Garden, Cozy Kitchen, and Dreamy Bedroom.
- Tap scene objects to add a beat to the story and collect story sparks. Spark totals are saved in the current browser with local storage.
- Expansion packs are shown as locked previews at the agreed one-time price of $5.99. A grown-up number gate blocks purchase prompts; payment is not connected.
- A separate grown-up corner explains this preview's local-only data behavior.

This is a front-end prototype, not a released game. It has no account system, backend, ads, or payment processing.
